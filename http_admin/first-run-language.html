Recommended Setup

A few optional add-ons make importing presentations work. You can do these now or later.

  1. PDF Import (Poppler)

    REVELation can download, install and enable the PopplerPDF plugin for you.

    Install it manually instead

    Download the PopplerPDF plugin ZIP from the releases page.

    Install it from the menu: Plugins → Install Plugin from ZIP…

    Then enable “PopplerPDF Binaries” under Settings → Plugins.

    Install it manually instead

    Install Poppler with Homebrew by running this in Terminal:

    brew install poppler

    Then restart REVELation.

    Install Poppler from your package manager, for example:

    sudo apt install poppler-utils # Debian / Ubuntu sudo dnf install poppler-utils # Fedora sudo pacman -S poppler # Arch

    Then restart REVELation.

  2. PowerPoint Import (LibreOffice)

    Install LibreOffice so PowerPoint files (.pptx, .ppt) can be imported. Without it, save your deck as a PDF and import the PDF instead.

    brew install --cask libreoffice
    sudo apt install libreoffice # Debian / Ubuntu

  3. Plugins

    Many features are plugins. Enable the ones you need under Settings → Plugins, such as Adventist Hymns and CCLI / Credits.
