Import PDF / PowerPoint

Each page is added as a full-screen slide image.
PowerPoint or PDF file

Accepts .pptx, .ppt, .ppsx, .pps, .odp and .pdf.

Speaker notes from PPTX (optional, for PDF exports of a PowerPoint)

Slide images are saved in this folder inside the presentation.

LibreOffice is needed to import PowerPoint files

LibreOffice is a free office suite. The app uses it in the background to turn PowerPoint files into PDF, then imports the pages. Download LibreOffice, install it, then click Check again.

Already installed? If LibreOffice is in an unusual location, set its path in Settings → Folders & Paths → Path to LibreOffice. Or save the deck as PDF from PowerPoint and import the PDF instead.
