## Atajos de teclado

<a id="builder-shortcuts-presentation"></a>

### Acciones de presentación

| Tecla | Acción |
|-----|--------|
| `Ctrl+S` | Guardar la presentación actual |
| `F5` | Mostrar la presentación completa (la presentación debe guardarse primero) |
| `Shift+F5` | Mostrar la presentación a partir de la diapositiva seleccionada |
| `Ctrl+E` | Alternar el editor entre las vistas **Visual** y **Markdown** (el interruptor Visual / Markdown / Split en el encabezado) |

---

<a id="builder-shortcuts-nav"></a>

### Navegación de diapositivas

Estos atajos mueven la selección activa en la lista de diapositivas. Las variantes con **Ctrl** funcionan en todas partes, incluso mientras editas texto; las teclas de flecha simples solo funcionan cuando ningún campo de texto tiene el foco.

| Tecla | Acción |
|-----|--------|
| `ArrowLeft` / `ArrowRight` | Columna anterior / siguiente |
| `ArrowUp` / `ArrowDown` | Diapositiva anterior / siguiente en la columna actual |
| `Ctrl+ArrowLeft` / `Ctrl+ArrowRight` | Columna anterior / siguiente |
| `Ctrl+ArrowUp` / `Ctrl+ArrowDown` | Diapositiva anterior / siguiente en la columna actual |
| `Ctrl+PageUp` | Ir a la primera diapositiva de la columna actual |
| `Ctrl+PageDown` | Ir a la última diapositiva de la columna actual |
| `Ctrl+Home` | Ir a la primera diapositiva de todas (columna 1, diapositiva 1) |
| `Ctrl+End` | Ir a la última diapositiva de todas (última columna, última diapositiva) |

---

<a id="builder-shortcuts-editing"></a>

### Edición de diapositivas

| Tecla | Acción |
|-----|--------|
| `Ctrl+M` | Agregar una nueva diapositiva después de la actual |
| `Ctrl+D` | Duplicar la diapositiva actual |
| `Ctrl+H` | Ocultar o mostrar la diapositiva actual |
| `Ctrl+L` | Crear una nueva columna |
| `Ctrl+Enter` | Dividir la diapositiva actual en la posición del cursor (se separa en dos diapositivas) |
| `Shift+Enter` | Insertar un salto de línea markdown (`\`) |

---

<a id="builder-shortcuts-plugins"></a>

### Creadores de contenido (atajos de plugins)

Estos atajos abren paneles de inserción de contenido. Solo están disponibles cuando el plugin correspondiente está habilitado.

| Tecla | Acción |
|-----|--------|
| `Ctrl+T` | Abrir el creador de Bible Text |
| `Ctrl+R` | Abrir la búsqueda de canciones de Hymnary |
| `Ctrl+W` | Abrir la búsqueda de Adventist Hymns |

<a id="builder-shortcuts-sorter"></a>

### Clasificador de diapositivas

El clasificador de diapositivas (Slide Sorter) es una vista a pantalla completa de arrastrar y soltar para reordenar diapositivas entre columnas.

| Tecla | Contexto | Acción |
|-----|---------|--------|
| `Escape` | Builder (Slide Sorter cerrado) | Abrir el Slide Sorter |
| `Escape` | Slide Sorter | Cerrar el Slide Sorter y volver al builder |
| `ArrowLeft` / `ArrowRight` | Slide Sorter | Columna anterior / siguiente |
| `ArrowUp` / `ArrowDown` | Slide Sorter | Diapositiva anterior / siguiente en la columna actual |
| `Home` | Slide Sorter | Ir a la primera diapositiva (columna 1, diapositiva 1) |
| `End` | Slide Sorter | Ir a la última diapositiva (última columna, última diapositiva) |
| `PageUp` | Slide Sorter | Ir a la primera diapositiva de la columna actual |
| `PageDown` | Slide Sorter | Ir a la última diapositiva de la columna actual |
